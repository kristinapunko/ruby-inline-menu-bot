# Ruby Inline Menu Telegram Bot

Навчальний Telegram-бот на Ruby, який демонструє роботу з кнопками під повідомленням. Команда `/menu` відкриває меню. Його кнопки дозволяють змінити поточне повідомлення, отримати нове або перейти до документації Telegram.

## Команди

| Команда | Дія |
| --- | --- |
| `/start` | Вітає користувача й пояснює, як відкрити меню. |
| `/menu` | Надсилає головне меню з чотирма кнопками. |
| `/help` | Показує доступні команди. |

## Кнопки

| Кнопка | Дія |
| --- | --- |
| 📚 Про проєкт | Замінює текст меню коротким описом бота. |
| ⚙️ Стек технологій | Показує використані технології в тому самому повідомленні. |
| 🎲 Випадкова порада | Надсилає пораду окремим повідомленням і залишає меню доступним. |
| ❌ Закрити меню | Прибирає кнопки та підказує, як знову відкрити меню. |
| ⬅️ Назад до меню | Відновлює головне меню з розділів «Про проєкт» і «Стек технологій». |
| 🔗 Документація Telegram | Відкриває опис Inline Keyboard у розділі «Про проєкт». |

## Встановлення та запуск

Потрібні Ruby, Bundler і токен бота від `@BotFather`.

1. Клонуйте репозиторій і перейдіть до його папки. Якщо проєкт уже є на комп’ютері, відкрийте термінал у папці з `Gemfile`.

   ```powershell
   git clone https://github.com/kristinapunko/ruby-inline-menu-bot.git
   cd ruby-inline-menu-bot
   ```

2. Встановіть бібліотеки `telegram-bot-ruby` і `dotenv`, перелічені в `Gemfile`.

   ```powershell
   bundle install
   ```

3. Створіть файл `.env` поруч із `Gemfile` і впишіть токен, отриманий від `@BotFather`.

   ```env
   BOT_TOKEN=ваш_токен_від_BotFather
   ```

   Перевірте, що в `.gitignore` є рядки `.env` і `*.bak`. Перед комітом переконайтеся, що ні файл із токеном, ні його резервна копія не додані до коміту.

4. Запустіть бота й надішліть йому `/menu` у Telegram. Щоб зупинити процес, натисніть `Ctrl+C` у терміналі.

   ```powershell
   bundle exec ruby bot.rb
   ```

## Як працює меню

Кнопки з `callback_data` передають боту ідентифікатор дії. Бот підтверджує натискання через `answer_callback_query`, щоб прибрати індикатор завантаження в Telegram. Для навігації він викликає `edit_message_text`, а для випадкової поради — `send_message`.

Кнопка «Документація Telegram» використовує параметр `url`. Посилання відкриває клієнт Telegram, тому для цієї кнопки бот не обробляє `CallbackQuery`.

## Перевірка

1. Надішліть `/menu` і натисніть «Про проєкт». Текст має змінитися в тому самому повідомленні.
2. Натисніть «Документація Telegram» і перевірте, що відкривається офіційна сторінка. Поверніться до чату й натисніть «Назад до меню».
3. Натисніть «Стек технологій» і перевірте повернення до меню.
4. Натисніть «Випадкова порада». У чаті має з’явитися нове повідомлення, а меню має залишитися доступним.
5. Натисніть «Закрити меню» і відкрийте його знову командою `/menu`.
